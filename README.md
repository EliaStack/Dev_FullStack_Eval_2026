## Comment lire les documents

1. Commencer par le **dossier professionnel**, qui présente mes réalisations et ma pratique professionnelle.
2. Poursuivre avec le **dossier de projet**, qui détaille la conception, l'architecture, les choix techniques, la sécurité, les tests et la mise en production de TaskFlow.
3. La **présentation** reprend les points clés du dossier de projet. Les notes de l'orateur sont dans le mode Présentateur de PowerPoint.

## Projet présenté : TaskFlow

TaskFlow est une application de gestion de projet : création de projets, gestion des membres, des tâches et des tags, avec des droits différents selon le rôle de l'utilisateur.

| | Technologies |
|---|---|
| **Backend** | Node.js, Express, MongoDB Atlas, Mongoose, JWT, bcrypt, Swagger |
| **Frontend** | React, Vite, React Router, Axios, Tailwind CSS |
| **Tests** | Jest, Supertest, mongodb-memory-server, Vitest, React Testing Library |
| **DevOps** | Docker, Docker Compose, GitHub Actions (CI/CD), Render, Vercel |
